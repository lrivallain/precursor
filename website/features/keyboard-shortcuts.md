# Keyboard shortcuts

Press **?** anywhere (or pick **Keyboard shortcuts** in the ⌘K palette) to see
the list in the app. On Windows and Linux, read ⌘ as **Ctrl**.

## Anywhere

| Keys | Action |
| --- | --- |
| **⌘K** / **Ctrl+K** | Open the command palette: jump to a section or conversation, search, or press **Tab** to [ask IQ](/features/iq#ask-from-k). |
| **/** | Open the command palette. |
| **⌘⇧K** / **Ctrl+Shift+K** | Open the [IQ section](/features/iq#the-iq-section), using the selected text as the question. |
| **C** | Focus the message composer. |
| **N** | Start a new item in the current section: the same action as the sidebar's **+** button. It does nothing on the home launcher or in IQ. |
| **?** | Show the shortcut list. |
| **Esc** | Close the open dialog or menu. |

The single-key shortcuts (**/**, **C**, **N**, **?**) only fire when you aren't typing in
a field and no dialog is open, so they never swallow a keystroke you meant to
type.

## Composer

| Keys | Action |
| --- | --- |
| **Enter** | Send the message. |
| **Shift+Enter** (or **Option/Alt+Enter**) | Insert a newline. |
| **↑** / **↓** | Recall earlier messages. |
| **Esc** | Stop the reply that is streaming. |

## Why these keys

None of them collide with a browser shortcut: the app avoids **⌘/Ctrl** + **N**,
**T**, **W**, **L**, **R**, **F**, **D** and the digits, which browsers reserve.

- **Requests through a tunnel are no longer trusted as local.** A request that came through a forwarding tunnel or proxy (it carries `X-Forwarded-*` headers) is now treated as remote: the MCP HTTP endpoint and the plugin installer refuse it even though the tunnel reaches Precursor on `127.0.0.1`. This is the groundwork for opening Precursor from your phone through a private tunnel: once remote access is on, a remote device must be paired with a one-time code before it gets in.

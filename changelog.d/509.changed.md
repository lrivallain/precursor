- **Agents mode runs on Microsoft Copilot SDK 2.0.** The `github-copilot-sdk` 1.x dependency is replaced by `microsoft-copilot-sdk` 2.0.1 (the same SDK, renamed). Agents and workflows behave as before; the native runtime is now a ~100 MB download (~180 MB on disk) cached under `copilot-sdk` instead of `github-copilot-sdk`, so Settings → Agents asks to install it again once after upgrading. Topics and chats are not affected.

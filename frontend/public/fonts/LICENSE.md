# Bundled fonts

These accessibility font faces are bundled to power the "Reading font" setting
(see `website/features/accessibility.md`). Both are distributed under the
[SIL Open Font License 1.1](https://openfontlicense.org/), which permits
bundling, use, and redistribution.

- **OpenDyslexic** — https://opendyslexic.org / https://github.com/antijingoist/opendyslexic
- **Atkinson Hyperlegible** — https://brailleinstitute.org/freefont / https://github.com/googlefonts/atkinson-hyperlegible
